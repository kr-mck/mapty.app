# mapty.app

Mapty.app is a small project I built during Jonas Schmedtmann's JavaScript course, with all improvements in this repo made entirely by me.
I added several enhancements to practice my JavaScript skills, especially the ability to edit and customize previously created workouts.
I also implemented the responsive layout myself.
Mapty is a small web application where you can add and store information about your sport activities, such as running and cycling.

You can use it here: https://km-mapty.netlify.app/
